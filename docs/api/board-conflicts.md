# 看板内容冲突

冲突指一次未能原子提交的看板写入批次。正文与元数据的取舍由调用方明确提供；命令负责保存事实、检查版本并提交结果。命令针对当前看板在本机保存的记录，不会查找其他电脑的冲突。

## 任务衔接

有 run 时，程序保存冲突并交给本任务 Agent，通过下列通用操作解决后继续原工作，无需用户手动续跑；没有 run 时只保留记录。复用本任务会话，不新增独立修复调度器。无法解决时保留数据和明确原因，用户停止后不自动继续。

## 列出冲突

```sh
akb board conflict list --json
```

只读，无需联网，不同步或重试。标准 JSON 成功响应增加 `conflicts` 数组；每项包含 `id`、`state`、`paths`。`state` 为 `open` 或 `unconfirmed`，后者表示提交结果尚未确认；没有待处理项时返回空数组。

## 读取冲突

```sh
akb board conflict show c_123 --json
```

只读，无需联网，不刷新云端。标准响应增加 `conflict`：

| 字段 | 含义 |
|---|---|
| `id` | 当前记录 ID |
| `revision` | 本次读取凭据，覆盖保存的批次事实和当前本地内容；提交时原样传回 |
| `state` | `open`、`unconfirmed` 或 `resolved` |
| `files` | 原批次的全部文件，包含下述字段 |
| `receipt` | 成功提交回执，未确认时为空 |

每个文件包含 `path`、`conflicted`、`reason`、`base`、`local`、`remote`、`working`。`path` 为命令返回的看板相对路径，原样用于解决文件；共享记忆的所属范围由绑定决定。`base`、`local`、`remote` 保存共同基础、被拒绝时的本地和云端版本，`working` 为读取时当前本地版本。各版本均有 `content`，缺失或删除为 JSON `null`；`base` 与 `remote` 另有 `seq`，已删除文件仍保留删除版本号，只有从未存在才为 0。

`reason` 区分双方修改、编辑与删除、新建同名文件或系统生命周期限制。未冲突成员也列出，以便理解原子边界。历史快照和未确认的解决草稿在结果确认前保留；命令不会把旧快照当作当前本地版本。`show` 不展开历史正文；如有草稿，`draft.record` 与 `draft.field` 指向本机记录中的原解决文件集合，供按需核对。

未知 ID、不可读或损坏的记录返回错误，不作为空冲突。普通离线读取不会把保存的云端版本标成最新。

## 提交解决结果

```sh
akb board conflict resolve c_123 --expect '<revision-from-show>' --file /tmp/resolution.json --json
```

`--file` 为 UTF-8 JSON 文件；唯一顶层字段 `files` 列出记录中每个 `conflicted: true` 的路径及最终 `content`，每个路径恰好一次：

```json
{"files":[{"path":"memory/readme.md","content":"保留双方有效决定后的正文\n"},{"path":"memory/obsolete.md","content":null}]}
```

字符串替换该文件内容，`null` 明确选择删除，空字符串表示保留空文件。不能通过此命令增加路径或遗漏冲突路径；原批次未冲突成员的修改原样保留。它不接受 Git 冲突标记作为解决指令。

命令使用当前登录、项目绑定和当前执行身份，不能继承记录中过期的作业身份。在原始写入批次上检查读取凭据、本地版本与云端 `seq`，再一次原子提交；卡片元数据沿用原有操作校验，不授予审批、恢复已删除任务或覆盖其他执行的权限。成功只在云端提交及本地回执核对后返回，响应增加 `id`、`state: "resolved"` 和 `receipt: {head_seq, files: [{path, seq}]}`。重复提交同一已确认结果返回已有回执，不产生新版本，不覆盖之后的编辑；改变结果必须重新读取当前事实。 当前任务依据确认回执自动继续原工作；本命令不批准任务、不重派整个任务，也不启动独立修复执行。

| 失败 | 结果 |
|---|---|
| `conflict` | 读取凭据、本地内容或云端版本变化；保留解决草稿，返回 `id` 与重新读取入口，不自动选择新内容 |
| `invalid-usage` | JSON、路径、文件集合或内容格式无效；不写入 |
| `conflict-not-found` | ID 不属于当前本机看板 |
| `cloud-refused` | 离线、未登录、无权限、失去执行权、任务生命周期或文件大小限制；原始内容保留，错误原因可读 |
| `unconfirmed` | 无法确认远端是否接受提交；保留草稿及待核对记录，不报告已解决 |

命令失败返回非零退出码和标准错误 envelope，并把原因交回本任务 Agent；单次命令失败不等于结束有 run 的任务。版本冲突不改变原批次中任何云端文件；不确定的提交通过原记录与现状核对，不因再次调用而重派任务。损坏记录只报错，不能清理成“已解决”。
