# Task-page buttons in Chinese

- **批准** — In the review flow when a prerequisite Preview is ready for approval. Dependent Previews can start once their prerequisites are approved.
- **执行** — In the header when the task is ready to run. Approves any ready independent Previews and starts execution.
- **停止** — In the header while a run is active and can be stopped.
- **继续执行** — In the run log for a stopped task or retryable failure when no run is active or queued.
- **丢弃这次执行** — In the run log when a run can be discarded. Confirming deletes its changes and branch and keeps the task and plan.
- **恢复** — In the header for completed or removed tasks with an available Studio. Returns the task to the board.
