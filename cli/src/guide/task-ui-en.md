# Task-page buttons

- **Approve** — In the review flow when a prerequisite Preview is ready for approval. Dependent Previews can start once their prerequisites are approved.
- **Execute** — In the header when the task can run. For older review plans, Execute can also approve the pending terminal Previews.
- **Stop** — In the header while a run is active and can be stopped.
- **Resume** — In the run log for a failed or stopped task. Continues from saved progress and shows any new refusal in the log.
- **Discard run** — In the run log when a run can be discarded. Confirming deletes its changes and branch and keeps the task and plan.
- **Restore** — In the header for completed or removed tasks with an available Studio. Returns the task to the board.
