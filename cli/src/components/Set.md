# Set

Group three or more previews of one purpose: a `<Set label="...">` line, one `<Asset ... />` per line, then `</Set>`, as one paragraph with no blank line inside. Inline and fenced examples remain text.

- **One purpose**: one set per purpose, such as a screen's states or the files you changed; keep one or two previews as plain Assets.
- **One item per label**: Assets sharing a `label` are one item; their `device` views, and a file beside its `.diff` or `.patch`, become switches on it.
- **Items**: anything an Asset shows, but not a compare or storyboard.
