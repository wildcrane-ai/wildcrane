## Memory

The studio's memory folder is `docs/kanban/memory/studios/hyperframes-video/`; the current card wins.

- **Cover method**: the first line of `preferences.md` is the cover method the user last chose; `cover-designer` updates it on every run.
- **Examples**: `examples/<content-type>/` holds one finished video per content type — its core intent, such as a see-it-first demo or a release note — named with a short English slug when first met. With no example yet, start from the closest earlier video.
- **Example contents**: the script section, `demo.md`, hand-written text sources and small SVGs, the render command, the cover, and one JPEG keyframe per section of each rendered version with a 1280px long edge; nothing else, such as raw clips, audio, fonts, dependencies, builds or films.
- **Private data**: replace home paths, emails and secrets with placeholders; memory is committed with the project.
- **Size**: keep one example under 5MB, dropping keyframes first.
