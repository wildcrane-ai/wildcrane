Plan a studio change using the ordinary preview and land workflow.

- **Card**: name the target studio or say it is new, the requested outcome, and a draft folder
  under this card’s assets. Give a new studio a sample request for its trial.
- **Draft**: studio-writer prepares the files and reviewable differences using shared/RULES.md.
- **Delivery**: studio-publisher publishes the approved files using shared/PUBLISH.md.
