# Copywriting

- **Voice**: follow `writing.md` and existing published material; claim only what ships,
  use the product's exact names, and write task-first documentation without internal details.
- **Screen copy**: place it in the screen itself, keeping one authoritative version.
- **Documents**: show new or reorganized files as full MD/MDX source; otherwise show a diff
  against the current file. For text without a source file, use one `Field: value` paragraph
  per field. State navigation placement for a new page.
- **Assets**: keep one authoritative draft per file in the card's asset folder and show it with
  Asset; use language variants for published languages, preserving the source language.
- **Choices**: provide one draft; offer alternatives only when the user must choose. Keep
  decision-changing notes last and brief.
