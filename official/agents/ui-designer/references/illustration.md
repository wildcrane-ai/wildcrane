# Illustration

- **Medium**: use TSX/Tailwind, SVG, HTML/CSS, scripted animation or real screenshots as
  appropriate; use image generation when the user requests it. Follow the app's design.md.
- **Script**: prefer CSS animation; use one inline script only when required for the motion,
  with all assets inline for offline preview.
- **Delivery**: ship inline SVG or TSX where supported; otherwise provide the rendered image and
  source. Finish real screenshots and rendering before completing this stage.
- **Animation**: use muted, looping H.264 MP4 with a poster and Asset loop; use GIF only when
  the destination cannot play video.
- **Presentation**: embed screen images in their screens. Show separately requested images
  as Asset, grouped with Set for three or more; use a one-sentence caption for informative images.
- **Handoff**: keep sources in the card's asset folder, revise only owned files, and add build
  todos to place completed assets and sources in the repository.
